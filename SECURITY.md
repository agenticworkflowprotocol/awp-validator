# Security Policy

Please do not open public issues for security problems. Report them privately via
[GitHub private vulnerability reporting](https://github.com/agenticworkflowprotocol/awp-validator/security/advisories/new)
or to info@agenticworkflowprotocol.org.

In scope: the validator accepting a manifest that the AWP specification requires to be rejected
(fail open), crashes or excessive resource use on crafted input, and the website.
Problems in the specification itself follow the
[security policy of the specification repository](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org/blob/main/SECURITY.md).

Only the latest release receives fixes until `1.0.0`.
