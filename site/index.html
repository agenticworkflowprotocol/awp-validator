Validate an AWP manifest

Checks the YAML restrictions, the JSON Schema and the semantic rules of AWP v1alpha1 for the conformance profiles you select. Validation runs entirely in your browser; the manifest is not uploaded.

Several documents separated by --- are validated one by one. Drop a file onto the editor to open it.

Supported profiles

Fields of profiles you do not select are rejected (spec 3.3).

    Use it in your application
    
      
    The same validator is available as a command-line tool, a Node.js library and a browser module without eval: npm install @agenticworkflowprotocol/validator. Every GitHub release also contains the package tarball and the browser bundle.
    
      
    
        
    
          
    Command line
    

    npm install --save-dev @agenticworkflowprotocol/validator
npx awp validate --profiles core,mcp workflow.yaml
npx awp validate --output json workflow.yaml
    
          
    Exit codes: 0 valid, 1 invalid, 2 usage error, 3 unreadable file.
    
        
    
        
    
          
    Node.js
    

    import { validateText, validateManifest } from '@agenticworkflowprotocol/validator';

const { documents } = validateText(yamlText, {
  file: 'workflow.yaml',
  profiles: ['core', 'mcp'],
});
const ok = documents.every((d) => d.valid);

// already parsed (e.g. a request body)
const result = validateManifest(manifest, { profiles: ['core'] });
